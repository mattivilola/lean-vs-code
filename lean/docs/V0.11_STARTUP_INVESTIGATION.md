## Source boundaries reviewed by GPT-6 Astra

The focused review on 30 September 2026 identified three optional boundaries. Its initial byte estimates came from existing emitted JavaScript with matching inline source maps; they are estimates, not rebuilt bundle deltas.

| Candidate | Safe boundary | Required invariants |
| --- | --- | --- |
| Main MCP HTTP routes/sessions | Extract the route implementation and load its constructor during the existing asynchronous first server start. | Keep the service/channel registered; load before accepting requests; synchronous server-change handling; deduplicate server starts; no late gateway after disposal or disconnect. |
| Shared-process browser automation | Register initialization options immediately; load Playwright implementation on the first real operation. | Preserve unawaited client initialization, per-context instance ownership, synchronous unsupported-event rejection, shared construction, retry, receiver/arguments/results, and disconnect/reconnect identity checks before construction and dispatch. |
| Shared-process remote CLI installer | Defer both SSH and dev-container installer imports to their existing asynchronous call sites. | Preserve channels, authentication, platform detection, command escaping, install/fallback outcomes and caller error handling. Both static edges must move. |

The main agent-host starter is already demand-driven at process-launch level. Preserve its early IPC, policy and shutdown listeners. Playwright's external package is already dynamically imported; no additional saving from that package is assumed. A whole ChatService proxy remains unsuitable because of synchronous model/reference/event contracts.

## First retained candidate

The [MCP route report](../performance/v0.11.0-mcp-gateway-route-lazy-cut.json) records a rebuilt isolated `app.ts` source graph: 2,070,863 to 2,055,580 unminified static JavaScript bytes, **15,283 fewer**. This includes the entry and its transitively static chunks with build/next's Node bundle options, not the renderer graph or a production package. Typecheck and changed-file lint pass. Seven real local-HTTP/lifecycle tests and sixteen existing session tests pass on Node 24.21.0.

The first test draft omitted the required MCP `notifications/initialized` handshake and correctly received a protocol error. The fixture was corrected; protocol behavior was preserved. Service-disposal and client-disconnect checks guard loading races, and a fault-injected first load confirms error propagation and retry.
